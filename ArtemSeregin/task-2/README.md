Условие: получить список элементов главной диагонали квадратной матрицы. Матрица представляется списком строк.

## Запуск

Открыть SWI-Prolog в этой папке:

```text
swipl -q -s main.pl
```

Ввести запрос, включая точку в конце, и нажать Enter:

```prolog
main_diagonal([[1, 2, 3], [4, 5, 6], [7, 8, 9]], Result).
% Result = [1, 5, 9].

main_diagonal([[1, 2], [3, 4]], Result).
% Result = [1, 4].

main_diagonal([[7]], Result).
% Result = [7].

main_diagonal([], Result).
% Result = [].
```

Для выхода: `halt.`. Символы `?-` перед запросом вводить не нужно.

## Как работает решение

Главная диагональ идёт из левого верхнего угла в правый нижний. У каждого её элемента номер строки совпадает с номером столбца. Нумерация в решении начинается с 1.

`main_diagonal/2` принимает матрицу и вычисляет диагональ. Предикат запускает вспомогательный `diagonal_rows/3` с номером строки 1.

1. Если строк больше нет, диагональ пуста. Это базовый случай.
2. В текущей строке выбирается элемент с номером `Index`.
3. Номер увеличивается на 1. Диагональ оставшихся строк вычисляется рекурсивно.
4. Выбранный элемент становится первым элементом результата, за ним следует результат рекурсивного вызова.

`element_at/3` выбирает элемент строки по номеру. Если нужен первый элемент, берёт голову списка. Иначе пропускает голову, уменьшает номер на 1 и повторяет поиск в хвосте.

В примере первая строка даёт первый элемент `1`, вторая — второй элемент `5`, третья — третий элемент `9`. Результат: `[1, 5, 9]`.

`[Head | Tail]` разделяет список на первый элемент и хвост. `is` вычисляет арифметическое выражение, `=:=` сравнивает числовые значения, `=` связывает переменную со значением. Конструкция `(Условие -> Тогда ; Иначе)` выбирает ветвь выполнения.

Перед извлечением диагонали проверяется форма входа: матрица должна быть списком строк, каждая строка — списком, а длина каждой строки должна совпадать с числом строк. Для неквадратной матрицы и строк разной длины предикат завершается с `false`. Пустая матрица `[]` трактуется как матрица размера 0×0.

В строке с номером I просматривается I элементов. Для матрицы N×N это 1 + 2 + ... + N обращений, то есть время O(N²). Глубина рекурсии — O(N).
