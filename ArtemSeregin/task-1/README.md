# Лабораторная № 1, вариант 27

Серегин Артём Валерьевич.

Условие: вставить заданное число после каждого вхождения указанного элемента списка.

## Запуск

Открыть SWI-Prolog в этой папке:

```text
swipl -q -s main.pl
```

Ввести запрос, включая точку в конце, и нажать Enter:

```prolog
insert_after([1, 2, 3, 2, 4], 2, 0, Result).
% Result = [1, 2, 0, 3, 2, 0, 4].

insert_after([2, 2], 2, 2, Result).
% Result = [2, 2, 2, 2].

insert_after([], 2, 0, Result).
% Result = [].
```

Для выхода: `halt.`. Символы `?-` перед запросом вводить не нужно.

## Как работает решение

`insert_after/4` — предикат с четырьмя аргументами: исходный список, искомый элемент, вставляемое число и результат. Первые три аргумента задаёт пользователь, четвёртый вычисляется. Список и искомый элемент должны быть без свободных переменных; вставляемое значение — число.

1. Для пустого списка результат — пустой список. Это базовый случай, который завершает рекурсию.
2. Непустой список разделяется на первый элемент `Head` и оставшийся список `Tail` записью `[Head | Tail]`.
3. Если первый элемент совпадает с искомым, результат начинается с `Head` и вставляемого числа. Иначе — только с `Head`.
4. Для исходного хвоста вызывается тот же предикат. Полученный список `Rest` дописывается к уже выбранному началу результата.

`==` сравнивает термы без присваивания значений переменным. Сравнение точное: целое `2` и дробное `2.0` — разные термы. `=` связывает переменную со значением или структурой. Конструкция `(Условие -> Тогда ; Иначе)` выбирает одну из двух ветвей.

Для примера из условия части результата получаются так: `[1]`, `[2, 0]`, `[3]`, `[2, 0]`, `[4]`. Вместе: `[1, 2, 0, 3, 2, 0, 4]`.

Вставленные числа не проверяются повторно: рекурсия идёт по `Tail` исходного списка. Поэтому запрос с одинаковыми искомым и вставляемым числами завершается.

Для списка длины N время работы — O(N), глубина рекурсии — O(N).
